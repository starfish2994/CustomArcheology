# 🏺 Welcome to CustomArcheology

**Enhance your server’s gameplay depth and player retention!**

CustomArcheology is a highly extensible gameplay plugin that expands Minecraft’s archaeology system introduced in 1.20.  
With it, you can turn archaeology into a fully custom feature — even making players believe your server runs a brand new mod!

---

## 🧱 Core Features

### 🔹 Custom Archaeology Blocks
- Create unlimited custom archaeology blocks.
- Fully configurable names, loot tables, excavation tools, animations, and replacement blocks.

### 🪓 Custom Archaeology Tools
- Add as many custom tools as you like.
- Set custom excavation speed, individual loot tables, display names, lores, and crafting recipes.

### 🎁 Custom Loot Tables
- Define unique loot tables per block.
- Trigger commands, spawn MythicMobs, teleport players, and more.
- Support for third-party plugins: **eco**, **MMOItems**, **MythicMobs**, **NeigeItem**, etc.
- Displayed loot and actual loot can differ to prevent exploitation.

### 🌍 Custom Generation Rules
- Configure generation rules for each block individually.
- Works even in loaded chunks without duplication.
- Limit generation by world, biome, height, or structure (e.g., Ancient City).
- Gaussian-based distribution mimicking vanilla ore spread.
- Customizable generation frequency per biome or structure.

### 🎨 Resource Pack Integration
- Automatically generates resource packs.
- Seamless integration with **ItemsAdder** and **Oraxen**.
- Supports a native **CraftEngine 26.8.2** block mode with automatic block and texture installation. See [CraftEngine mode](docs/craftengine.md).
